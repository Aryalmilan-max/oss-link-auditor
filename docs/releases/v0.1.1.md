# OSS Link Auditor v0.1.1

This maintenance release keeps the reusable GitHub Action current and removes
the Node 20 deprecation warning seen by consumers of `v0.1.0`.

## Changed

- Updated `actions/checkout` to `v7.0.1` using a full commit SHA.
- Updated `actions/setup-python` to `v7.0.0` using a full commit SHA.
- Expanded the supported mypy development range to `>=1.13,<3`.
- Added GitHub Discussions as the destination for usage questions and ideas.

## Verification

- Python 3.10, 3.12, and 3.13 CI jobs pass.
- The deterministic local demo passes.
- A separate public consumer workflow uses this Action successfully.

Existing CLI behavior is unchanged. See the
[v0.1.0 release notes](https://github.com/Aryalmilan-max/oss-link-auditor/releases/tag/v0.1.0)
for the complete feature overview.
