# OSS Link Auditor v0.1.0

First public release of the source-aware Markdown trust report.

## Highlights

- CLI and reusable GitHub Action with no runtime dependencies.
- Exact source file and line for every unique link.
- Separate healthy, redirect, cross-host redirect, broken, and blocked results.
- Text, JSON, and Markdown output; Action reports appear in Step Summary.
- Public-network validation for initial and redirected targets.
- Deterministic offline demo and Python 3.10-3.13 test matrix.

## Security note

Application-level DNS validation cannot replace runner network isolation. Do
not audit untrusted pull-request content on self-hosted runners with access to
internal services. Read the full [security policy](../../SECURITY.md).

## Verification
